## 2. 研究问题与假设

- **主问题**：NPO 对 BKS 海冰的影响是否存在年代际变化？如果是，是什么在调制它？
- **假设 A（遥相关路径）**：NPO 通过向极传播的 Rossby 波列，在北大西洋低层制造环流异常，
  进而改变向 BKS 的热量 / 水汽输送。
- **假设 B（背景态调制）**：年代际变化来自北太平洋或热带背景态（如 PDO 位相）对波列路径的调制，
  而不是 NPO 本身强度的变化。
- **竞争解释**：海冰自身的厚度 / 记忆变化，使同一天气尺度强迫在不同年代产生不同响应。
- **已排除**：（暂无）

## 5. 给 AI 的常驻规则

1. **先对齐再动手**：超过 20 行的代码或分析方案，先用三句话复述任务、列出假设，等我确认。
2. **小步交付**：一次一个可验证的产物（一个函数 / 一张图 / 一段 300 字）。
3. **代码**：给完整可运行版本，注明依赖；不要用我没装过的库；不要写死本地路径。
4. **统计**：涉及显著性必须说明检验方法、前提，以及有没有处理空间自相关。
5. **机制**：讨论机制时先给物理链条（动量 / 热量 / 水汽怎么走），再给统计证据；
   **不要用"显著"代替"机制"**。
6. **结论**：把"相关"和"因果"分开说；给机制解释时列出竞争假设。
7. **溯源**：文献、数据版本、具体数值必须给出处，我自己核验。
8. **不确定就说不确定**，不要用"看起来合理"的数字填空。
9. **不要**生成参考文献列表；**不要**建议改动 `/data` 下任何文件。
10. 语言：中文回答，代码注释中文，**图内文字用英文**（服务器没有中文字体）。
